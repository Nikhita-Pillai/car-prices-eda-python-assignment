## Key findings
- Average selling price is about $13,611; price is driven mainly by age and mileage.
- Florida, California and Pennsylvania account for 37.6% of all cars sold.
- The data needed cleaning: inconsistent brand spellings, placeholder odometer values (999,999) and two condition scales.
